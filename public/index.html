Find local trade vendors

Use when you need a clean list of real local businesses in a trade and a city, with phone, website, and address.

An agent sends a trade and a city. This endpoint returns the businesses OpenStreetMap actually has on the map, plus a receipt for the call.

POST /v1/find
X-Api-Key: sandbox

{
  "trade": "HVAC",
  "city": "Dallas, TX",
  "max_results": 10
}

Example result: name, phone, website, email if OSM has one, address, coordinates, OSM id, source URL, and a one-line receipt (time, input, result count, cost).

Sandbox key sandbox is three free calls a day. Paid calls are $0.50, with a $25 daily cap unless the owner raises it.
